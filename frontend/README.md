# StudyOS Frontend

Complete React + Tailwind UI for the StudyOS academic intelligence application.

## Run

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

## Included

- Academic dashboard
- Subject management
- Five-module subject structure
- Module/topic progress tracking
- Daily adaptive study plan UI
- Assessments and exam countdowns
- Study analytics
- Past-question intelligence
- AI mastery/risk/recommendation UI
- SGPA target planner
- Responsive mobile sidebar
- Dark academic navigation and polished dashboard cards

The UI currently uses realistic local demo data. The backend folder is preserved from the original empty architecture ZIP and is ready to be connected through `src/services/api.js`.
